# 编辑与翻译规范（阶段 1 草案）

本规范先用于 OCR 试验；完成代表页校订后再冻结为 1.0 版。

## 五个不可互相覆盖的数据层

1. **Facsimile**：扫描页及其来源、物理页／印刷页标识。
2. **Diplomatic transcription**：按底本转录的德文和外语文字，保留历史拼写、大小写、标点、段落、诗行与显著版面关系。
3. **Normalized German**：展开排印连字、合并普通换行断词、统一机器检索所需的 Unicode；不擅自现代化词汇或语法。
4. **Chinese translation**：以段落／诗行为单位与原文稳定对齐。
5. **Notes**：人名、地名、引文来源、异文、双关、排版巧思和不确定读法。

## OCR 金标准的字符规则

- 保留原书拼写、大小写、变音符号、`ß`、标点和印刷页码。
- Fraktur 的长 s 字形 `ſ` 录作普通 `s`；纯排印连字如 `ﬀ`、`ﬁ`、`ﬂ` 展开为 `ff`、`fi`、`fl`。
- 保留每一条印刷行的换行；行末印刷连字符暂时保留。去断词只发生在 normalized 层。
- 页眉、页脚、脚注、正文都录入。页边馆藏章、铅笔号、扫描平台水印不录入正文，可在注释层描述。
- 多栏按“左栏从上到下，再右栏从上到下”的阅读顺序。若底本另有明确的跨栏阅读关系，在页级注释中说明。
- 无法确认的字符使用 `⟦unclear:可见字形⟧`；不要凭现代语感补字。评分脚本会把这类标记视为待裁决，而不是可靠金标准。

## 特殊版面

离合诗、名单、音乐例、折页与书信不能只保存为扁平段落。后续正式数据应至少记录：

- 页面和区域 ID；
- 行的阅读顺序；
- 原始换行和缩进；
- 类型（如 `acrostic`、`poem`、`letter`、`music`、`index`）；
- 可计算的隐含读法，例如 `acrostic = PAGANINI`；
- 译文如何对应原诗行，及中文是否另作离合诗尝试。

正式发布建议以“每页一个 TEI XML 文件”为权威文本，以 JSON 作为网站构建产物。阶段 1 暂用 UTF-8 纯文本，以降低人工校订门槛。

## 翻译原则

- 第一版以准确、完整和可回查为先，不为了流畅删除重复、夸张或时代性的措辞。
- 人名、报刊、曲名和机构名建立统一术语表；首次出现可并列原文。
- 原书中的意大利文、法文、拉丁文等先按原语言校订，再翻译；不得把错误的德语 OCR 当作外语原文。
- 离合诗等形式内容同时给出“意义译文”和“形式说明”；若另作中文形式再现，应明确标为译者创作方案。
- 机器翻译可以生成草稿，但不能在未经逐段人工复核时标为定稿。
