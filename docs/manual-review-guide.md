# 人工金标准：逐页操作说明

人工工作只做一件事：以扫描图为依据，把该页所有印刷文字准确录入对应的 `.gt.txt`。不要翻译，不要现代化德文，也不要尝试一次处理全书。

## 每一页的操作

1. 打开 `pilot/images/page-NNN.png`，放大到能区分字母和标点。
2. 打开 `pilot/ground_truth/page-NNN.gt.txt`，按视觉阅读顺序逐行录入。
3. 依照 [`editorial-policy.md`](editorial-policy.md) 处理长 s、连字、换行和疑字。
   本书常见字形可先查 [`fraktur-quick-reference.md`](fraktur-quick-reference.md)。
4. 可以把 `pilot/ocr/` 下的候选结果放在旁边参考，但每个字符都必须回到图像核对。
5. 保存为 UTF-8；不要在文件中加入“第几页”“完成”等说明。
6. 完成人工校对后通知维护者进行第二底本复核。只有 `pilot/ground_truth/review-log.csv` 标为 `verified` 的页才会在运行 `python scripts/score_ocr.py` 时出分；有内容的草稿不会计入。

## 推荐的逐页顺序

先从常规正文建立手感，再处理混排和特殊版面：

```text
021 → 060 → 115 → 174 → 220 → 266 → 339 → 420
→ 009 → 005 → 019 → 015 → 043 → 044 → 438
```

PDF 第 442 页是手写折页，不要求制作印刷体 OCR 金标准；只需记录它是否需要意大利语手稿专家、音乐材料专家或两者。

## 质量要求

- 一页完成后，从末行倒序快速复核一次，较容易发现漏行。
- 数字、专名、引号、破折号和行末断词是最常漏的内容。
- 目录／索引按左栏后右栏录入；离合诗必须让每一诗行的起始字母仍可顺次读出 `PAGANINI`。
- 若图像确实无法辨认，使用 `⟦unclear:...⟧`，并把该页列入 MDZ 校本复核；不要猜。
