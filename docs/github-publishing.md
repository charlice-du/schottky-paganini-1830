## 公开仓库内容边界

建议提交：脚本、页码表、来源清单、OCR 试验文字、人工转录、原创译文、注释和网站代码。

暂不提交：原始扫描 PDF、MDZ／Google 整页图像、Tesseract 模型和大体积 OCR 缓存。网站通过 IA／MDZ 的 IIIF 或外链载入图像；如果未来确认可以再分发，再单独讨论 Git LFS 或 release assets。
